  SOLUCIÓN AUTOMÁTICA - SIN COMANDOS LOCALES
═══════════════════════════════════════════════════════════

NO NECESITAS INSTALAR NADA EN TU PC

El workflow de GitHub Actions ya está configurado para:
✅ Instalar VitaSDK automáticamente
✅ Compilar la versión completa
✅ Crear el VPK
✅ Generar checksums
✅ Subir el release

═══════════════════════════════════════════════════════════
OPCIÓN 1: Activar desde GitHub Web (MÁS FÁCIL)
═══════════════════════════════════════════════════════════

1. Ve a: https://github.com/kkakele/VitaCast/releases

2. Borra manualmente las releases anteriores:
   - Click en cada release
   - Click "Delete this release"
   - Confirmar

3. Ve a: https://github.com/kkakele/VitaCast/tags

4. Borra los tags antiguos:
   - Click en "..." junto a cada tag
   - Delete tag

5. Ve a: https://github.com/kkakele/VitaCast/actions

6. Click en "Build VitaCast Release"

7. Click en "Run workflow" (botón derecho)

8. Escribir versión: 1.0.0

9. Click "Run workflow" (verde)

10. Esperar 15-20 minutos

11. Ve a: https://github.com/kkakele/VitaCast/releases
    ¡Tu VPK estará listo para descargar!


═══════════════════════════════════════════════════════════
OPCIÓN 2: Si solo quieres borrar releases y subir tag
═══════════════════════════════════════════════════════════

Ejecuta estos 3 comandos UNO POR UNO (espera que termine cada uno):

gh release delete v2.0.1 --yes

git tag v1.0.0 -m "Release v1.0.0"

git push origin v1.0.0


Eso es todo. GitHub Actions se encarga del resto.


═══════════════════════════════════════════════════════════
¿POR QUÉ SE INTERRUMPEN LOS COMANDOS?
═══════════════════════════════════════════════════════════

Posibles causas:
- Windows Defender bloqueando gh.exe
- PowerShell con timeout muy corto
- Proceso de Cursor interfiriendo

Solución: Usa GitHub Web (Opción 1) y evita ejecutar comandos locales.
