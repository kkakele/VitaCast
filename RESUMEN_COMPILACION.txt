## OPCIONES PARA COMPILAR VERSION COMPLETA

### OPCION 1: Instalar WSL2 Manualmente (REQUIERE ADMIN)

**Pasos que TÚ debes hacer:**

1. **Abrir PowerShell como Administrador:**
   - Click derecho en PowerShell
   - "Ejecutar como administrador"

2. **Ejecutar:**
   ```powershell
   wsl --install
   ```

3. **Reiniciar PC** (si te lo pide)

4. **Después de reiniciar:**
   - Abre Ubuntu desde el menú inicio
   - Configura usuario y contraseña
   - Ejecuta: `.\INSTALAR_Y_COMPILAR.ps1 -SkipInstall`

5. **Compilar:**
   ```powershell
   .\INSTALAR_Y_COMPILAR.ps1 -SkipInstall
   ```

**Tiempo total:** 30-40 minutos (con instalación)

---

### OPCION 2: Usar Docker (SI LO TIENES)

**Si tienes Docker Desktop instalado:**

```powershell
docker pull vitasdk/vitasdk:latest
docker run -it --rm -v ${PWD}:/build vitasdk/vitasdk bash -c "cd /build && make -f Makefile_final release"
```

**Ventaja:** No necesitas instalar nada permanentemente
**Desventaja:** Descarga ~2GB cada vez
